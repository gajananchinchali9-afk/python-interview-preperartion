# Python Interview Questions and Answers

1. What is Python?
   Answer: Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum. It is known for its simplicity, readability, and wide use in web development, automation, data science, AI, cybersecurity, and scripting.

2. What are its features?
   Answer:
   - Easy to read and write
   - Interpreted language
   - Dynamically typed
   - Cross-platform support
   - Large standard library and third-party packages
   - Supports object-oriented, functional, and procedural programming
   - Good for rapid development and prototyping

3. What are the advantages and disadvantages of Python?
   Answer:
   Advantages:
   - Simple syntax and beginner-friendly
   - Large community support
   - Huge ecosystem of libraries
   - Portable and flexible
   - Great for automation and data analysis

   Disadvantages:
   - Slower than compiled languages like C/C++
   - Not ideal for mobile app development
   - Memory consumption can be higher
   - Runtime errors may appear during execution

4. What are the versions of Python?
   Answer: The two main branches are Python 2 and Python 3. Python 3 is the current and recommended version, while Python 2 reached end-of-life and is no longer supported.

5. What is the most stable version of Python?
   Answer: Python 3 is the stable and actively maintained version. In most modern environments, the latest Python 3 release is recommended, especially Python 3.12 or newer for long-term stability and support.

   - venv / virtualenv (virtual environments)
   - IDEs such as VS Code, PyCharm, and Jupyter Notebook
   - Git for version control

7. What is the extension used to save a Python file?

11. How does Python work internally?
   Answer: Python reads the source code, compiles it into bytecode, and then executes that bytecode using the Python Virtual Machine (PVM). The bytecode is platform-independent, while the PVM handles execution on the operating system.

12. Explain Python architecture.
   Answer: Python architecture consists of:
   - Source code written by the developer
   - Python parser that converts code into an abstract syntax tree (AST)
   - Compiler that converts it into bytecode
   - Python Virtual Machine (PVM) that executes the bytecode
   - Operating system and hardware provide runtime support

13. What is indentation in Python, and why is it used instead of semicolons or braces?
   Answer: Indentation defines blocks of code such as loops, conditions, functions, and classes. Python uses indentation to improve readability and enforce a consistent structure. Unlike C, Java, or C++, Python does not use braces {} or semicolons ; to define blocks, so indentation is mandatory.

15. What are variables in Python, and how do they differ from other programming languages?
   Answer: Variables are containers used to store data values. In Python, variables do not require explicit type declarations. For example: x = 10, name = "Alice". Unlike many languages, Python uses dynamic typing, so the variable type is determined at runtime.

16. What are data types in Python, and how do they differ from other backend programming languages?
   Answer: Python has built-in data types such as:
   - int: integer values
   - float: decimal values
   - str: text
   - bool: True/False
   - list: ordered mutable collection
   - tuple: ordered immutable collection
   - set: unordered unique items
   - dict: key-value pairs
   - NoneType: no value

   Python is dynamically typed, while many backend languages like Java or C# are statically typed and require explicit type declarations.

17. What are functions in Python, and how do they differ from other backend programming languages? Explain with syntax and example.
   Answer: A function is a reusable block of code that performs a specific task. In Python, a function is defined using the def keyword.

   Example:
   ```python
   def add(a, b):
       return a + b

   result = add(5, 3)
   print(result)
   ```

   Python functions are simpler and more flexible than many backend languages because they are first-class objects and can be passed as arguments, assigned to variables, or returned from other functions.

18. What are the types of functions in Python? What are arguments and parameters in Python?
   Answer: Types of functions include:
   - Built-in functions
   - User-defined functions
   - Lambda functions
   - Recursive functions
   - Higher-order functions

   Parameters are variables listed in a function definition, while arguments are the actual values passed when calling the function.

   Example:
   ```python
   def greet(name):   # name is a parameter
       print("Hello", name)

   greet("Alice")    # "Alice" is an argument
   ```

   Common argument types are positional arguments, keyword arguments, default arguments, variable-length arguments, and keyword variable arguments.

19. What is the difference between a list and a tuple in Python?
   Answer: A list is mutable, which means its contents can be changed after creation. A tuple is immutable and cannot be modified after creation. Lists use square brackets [], while tuples use parentheses ().

20. What is a dictionary in Python?
   Answer: A dictionary stores data in key-value pairs. It is unordered in older versions but ordered by insertion in Python 3.7+. Example: student = {"name": "Alice", "age": 20}.

21. What is the difference between Python and Java/C++?
   Answer: Python is simpler, easier to read, and dynamically typed, while Java and C++ are more verbose and statically typed. Python is often preferred for scripting, automation, and quick development, while Java and C++ are common in enterprise and systems programming.

22. What is the difference between Python 2 and Python 3?
   Answer: Python 3 fixes many design issues in Python 2, uses clearer syntax, has improved Unicode support, and is actively maintained. Python 2 is outdated and no longer supported.

23. What is the purpose of pip in Python?
   Answer: pip is the package installer for Python. It is used to install, upgrade, and remove third-party libraries such as NumPy, Pandas, Flask, and Django.

24. What is virtual environment in Python?
   Answer: A virtual environment is an isolated directory containing its own Python interpreter and installed packages. It helps avoid dependency conflicts between different projects.

25. What is the difference between a module and a package in Python?
   Answer: A module is a single Python file containing code. A package is a folder that contains multiple modules and a special __init__.py file (in older Python versions) to define it as a package.

26. What is OOP in Python?
   Answer: Object-Oriented Programming (OOP) organizes code into classes and objects. Python supports classes, inheritance, encapsulation, and polymorphism.

27. What is a class in Python?
   Answer: A class is a blueprint for creating objects. It defines attributes and methods that objects will have.

   Example:
   ```python
   class Car:
       def __init__(self, brand):
           self.brand = brand

   c = Car("Toyota")
   print(c.brand)
   ```

28. What is inheritance in Python?
   Answer: Inheritance allows a child class to reuse the properties and methods of a parent class. It helps reduce duplication and improves maintainability.

29. What is polymorphism in Python?
   Answer: Polymorphism means the same method or function can behave differently based on the object calling it. It is a core concept in object-oriented programming.

30. What is exception handling in Python?
   Answer: Exception handling is used to manage runtime errors without stopping the program. It uses try, except, else, and finally blocks.

   Example:
   ```python
   try:
       x = 10 / 0
   except ZeroDivisionError:
       print("Cannot divide by zero")
   finally:
       print("Execution completed")
   ```

31. What is the difference between list, set, and tuple?
   Answer:
   - List: ordered, mutable, allows duplicates
   - Tuple: ordered, immutable, allows duplicates
   - Set: unordered, mutable, unique values only

32. What is the use of __init__ in Python classes?
   Answer: __init__ is a special method called automatically when an object is created. It is used to initialize object attributes.

33. What is a lambda function in Python?
   Answer: A lambda function is a short anonymous function defined using the lambda keyword. It is commonly used for quick one-line operations.

   Example:
   ```python
   square = lambda x: x * x
   print(square(5))
   ```

34. What is recursion in Python?
   Answer: Recursion is when a function calls itself. It is useful for problems like factorial, Fibonacci, and tree traversal, but it should be used carefully to avoid infinite recursion.

35. What is the difference between deep copy and shallow copy?
   Answer: A shallow copy creates a new object but copies references to nested items, while a deep copy creates a fully independent copy of all nested objects.

36. What is the purpose of Python comments?
   Answer: Comments improve code readability and help developers explain logic. Single-line comments use #, and multi-line comments use triple quotes or multiple # lines.

37. What is the use of range() in Python?
   Answer: range() generates a sequence of numbers and is most commonly used in loops.

   Example:
   ```python
   for i in range(5):
       print(i)
   ```

38. What are generators in Python?
   Answer: Generators are functions that yield values one at a time instead of returning all results at once. They are memory-efficient and useful for large datasets.

39. What is list comprehension in Python?
   Answer: List comprehension is a concise way to create lists in a single line.

   Example:
   ```python
   squares = [x * x for x in range(5)]
   print(squares)
   ```

40. What are decorators in Python?
   Answer: Decorators are functions that modify or extend the behavior of another function without changing its code directly. They are often used for logging, authentication, and validation.

41. What is the purpose of __name__ == "__main__" in Python?
   Answer: It allows code to run only when the file is executed directly, not when it is imported as a module.

   Example:
   ```python
   if __name__ == "__main__":
       print("This runs as a script")
   ```

42. What is the difference between append() and extend() in Python lists?
   Answer: append() adds a single element to the end of the list, while extend() adds multiple elements by iterating through an iterable.

43. What is slicing in Python?
   Answer: Slicing allows accessing or modifying a subset of a sequence using index ranges.

   Example:
   ```python
   name = "Python"
   print(name[0:3])
   ```

44. What is the use of join() in Python strings?
   Answer: join() combines elements of a list into a single string using a specified separator.

   Example:
   ```python
   words = ["Python", "Interview", "Questions"]
   print(" ".join(words))
   ```

45. What is the difference between break and continue?
   Answer: break exits the loop immediately, while continue skips the current iteration and moves to the next one.

46. What is the difference between pass and return in functions?
   Answer: pass is a placeholder that does nothing; return sends a value back from a function and ends its execution.

47. What is the purpose of map(), filter(), and reduce()?
   Answer:
   - map(): applies a function to each item
   - filter(): keeps items that satisfy a condition
   - reduce(): combines items into a single result

48. Why is Python widely used in AI and data science?
   Answer: Python has powerful libraries such as NumPy, Pandas, Matplotlib, Scikit-learn, TensorFlow, and PyTorch, which make it suitable for machine learning, data processing, and AI projects.

49. What is the difference between local and global variables?
   Answer: Local variables are defined inside a function and accessible only there. Global variables are defined outside functions and can be accessed anywhere in the module.

50. What are the best practices for Python programming?
   Answer:
   - Use proper naming conventions
   - Write readable code
   - Keep functions small
   - Use docstrings and comments when needed
   - Follow PEP 8 style guidelines
   - Use virtual environments
   - Handle exceptions properly
   - Write test cases for logic validation
